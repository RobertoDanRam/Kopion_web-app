# Kopion & La Capital del Café - Web App

## Project Description
Sistema de gestión descentralizado para la papelería "Kopion" y la cafetería "La Capital del Café". El proyecto administra un inventario multi-sucursal con clasificación de artículos (Venta vs. Consumo Interno), control de asistencia de empleados, procesamiento de órdenes con colas de impresión de archivos, y un flujo de trabajo de "Aprobación a un clic" para movimientos de inventario y vales de pago.
